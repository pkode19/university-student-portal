# University Student Portal

A simple Python project developed as a Git and GitHub collaboration exercise.

## Features

- Collects student full name
- Collects Student ID
- Collects programme
- Collects level
- Collects age
- Collects hall of residence
- Generates a student email using string concatenation
- Displays a formatted student profile
- Supports collaborative development using Git branches and Pull Requests

## Collaboration

Developer A implements the student registration and generated email feature.

Developer B implements the Contact Line feature using the generated email, hall of residence, and programme.
